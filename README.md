# Гадания и гороскоп

Мини-приложение для ВК и ОК: карта дня, «да или нет», гороскоп на сегодня (и на завтра — за рекламу),
совместимость знаков, «поделиться» с открыткой-картинкой. Playgama Bridge — одна сборка для ВК и ОК.
Открыть: `index.html` (статический сайт, например GitHub Pages:
https://romangerasimov71-spec.github.io/fortune-horoscope-/ ; проба рекламы — `?fakeads=1`).

- Что есть и как устроено — `docs/BUILD.md`.
- Как перенести основу (площадка, реклама, «поделиться», статистика) в другое мини-приложение — `docs/TEMPLATE.md`.
- События статистики — `docs/analytics.md`.
- Тексты — в `content/`. Проверка — `tools/check.js` и `tests/ads-test/`.

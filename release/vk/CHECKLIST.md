## Площадки
- ВК и ОК — одно приложение в кабинете ВК, ОК привязывается там же.
- Playgama и Яндекс Игры — не делаем (это мини-приложение, не игра).

## Тип приложения в кабинете — ВОПРОС РОМАНУ / проверить на месте
PUBLISH.md и навык писали для игр («Тип — Игра»). Приложение у нас не игра, но:
- Одна сборка работает через Playgama Bridge, как у игр; привязка ОК и реклама (Bridge) настроены под связку «ВК + ОК».
- Рекомендация: **сначала открыть форму создания и посмотреть, предлагает ли «Мини-приложение» кнопку «Другие площадки → OK»**. Если да — выбрать «Мини-приложение» (честнее по смыслу, мягче модерация). Если привязка ОК есть только у «Игры» — выбрать «Игра» с жанром «Другое»: так приложение попадёт в ОК, где наша основная аудитория (40+), а модерация игр проверена на практике 9 ноября.
- Что именно в кабинете — не знаю наверняка, потому и вопрос. Роману ответ не нужен, если Костя увидит оба варианта и привязка ОК есть у «Мини-приложения»; если неочевидно — спросить Романа «⛔ ЖДУ ТЕБЯ: тип Игра или Мини-приложение?».

## Что делает Костя / начальник (встроенный браузер на Маке)
1. Открыть `dev.vk.ru/ru/admin/create-app`, выбрать тип (см. выше), название «Гадания и гороскоп», жанр/категория из `texts.md` → «Создать». (⛔ см. ниже: пуш Роману.) Записать ID приложения.
2. Информация: краткое описание (94 знака), слоган (29), полное описание, Company Name — из `texts.md`. Сохранить.
3. Размещение: Состояние «Включено»; URL для мобильного, Web и мобильной версии — ссылка GitHub Pages. Сохранить. Проверить `vk.ru/app<ID>` — приложение грузится.
4. Отображение: Книжная; кнопки «Над окном»; адаптация под iPhone «Отключена». Сохранить.
5. Оформление → Иконки: `icon-576.png` (универсальная), `favicon-32.png`. Изображения: `snippet-1120x630.png`; переключить «Книжная» и по одному загрузить `screen-1-main.png` … `screen-5-yesno.png` (600×1200, 5 штук, минимум 3), после каждого перезагрузить страницу. Загрузка: fetch с `raw.githubusercontent.com` → File → DataTransfer → input (как в PUBLISH.md).
6. Правовые документы: «Использовать типовые документы». Сохранить.
7. Записать ID в `config.js`: `vkAppId: '<ID ВК>'`, `okAppId: '<ID ОК>'` (чтобы «Поделиться» вело в приложение, а не на GitHub Pages) → commit + push в `main`, проверить, что на Pages открывается свежая версия (кнопки «Поделиться» ведут на vk.com/app<ID> и ok.ru/game/<ID>). ID ОК виден после привязки (шаг ниже «ID профиля»).
8. Модерация: когда всё зелёное — одна заявка, площадки ВКонтакте и Одноклассники.
9. После одобрения — «Монетизация» → включить рекламу.
10. Обновить `STATUS.md`, карточку на доске (`games/fortune-horoscope-`), ленту; вписать ссылки vk.com/app<ID> и ok.ru/game/<ID>.
